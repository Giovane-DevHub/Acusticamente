1. O QUE É O PROJETO
--------------------------------------------------------------------------------
Sistema web completo para gestão de escola de música (alunos, agenda, financeiro e relatórios).

- Acesso inicial:
  Login : 1
  Senha : 1


2. TELAS DO SISTEMA
--------------------------------------------------------------------------------
Início : Visão geral com resumo do dia e próximas aulas
Agenda : Calendário com horários de aulas e controle de reposições
Alunos : Cadastro de alunos, ficha pedagógica e histórico
Financeiro : Controle de mensalidades, cobranças e baixas de pagamento
Planos : Cursos oferecidos, valores e módulos de ensino
Relatórios : Emissão e impressão de relatórios de alunos e finanças em PDF
Usuários : Cadastro de professores e atendentes com controle de permissões
Auditoria : Registro automático de quem fez cada alteração no sistema
Configurações : Dados da escola (nome, logotipo, contatos e CNPJ)
Login : Tela de entrada com usuário e senha


3. ESTRUTURA DE ARQUIVOS
--------------------------------------------------------------------------------
api/ : Conexão e sincronização direta com o MongoDB Atlas na Vercel
src/views/ : Telas visuais do sistema que o usuário vê e usa
src/services/ : Regras que salvam dados, calculam valores e controlam acesso
src/types/ : Definições do que cada cadastro possui (aluno, aula, etc.)
src/styles/ : Cores, botões, responsividade e visual do sistema
src/utils/ : Ferramentas auxiliares (avisos, datas e janelas pop-up)


4. CORES PRINCIPAIS
--------------------------------------------------------------------------------
Fundo Escuro (#17181f) : Cor de fundo principal de todas as telas
Coral Vibrante (#ea4335) : Cor dos botões principais e destaques
Texto Claro (#ffffff) : Cor dos textos para leitura nítida
Cartões (#1f212b) : Cor dos painéis e caixas de informação


5. COMO RODAR O PROJETO
--------------------------------------------------------------------------------
npm run dev : Inicia o sistema para testes no computador
npm run build : Prepara os arquivos finais para publicação na nuvem
