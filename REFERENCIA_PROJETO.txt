1. O QUE É O PROJETO
--------------------------------------------------------------------------------
Sistema web completo para gestão de escola de música (alunos, agenda, planos pedagógicos, financeiro, planos de pagamento e auditoria).
Multi-dispositivo com sincronização em tempo real na nuvem via MongoDB Atlas e Vercel.

- Acesso inicial:
  Login : 1
  Senha : 1
  URL Produção : https://acusticamente.vercel.app


2. TELAS DO SISTEMA
--------------------------------------------------------------------------------
Início : Visão geral com resumo do dia e próximas aulas
Agenda : Calendário de aulas com opção de gerar aulas semanais em lote a partir do plano pedagógico e agendamento de reposições integrado ao saldo de créditos
Alunos : Matrículas com vinculação ao Plano Pedagógico e ao Plano de Pagamento (desconto automático de 20% na 2ª matrícula), exibição somente-leitura do saldo de remarcações, máscaras (CPF/celular) e validação de menor de 18 anos
Planos de Ensino : Estrutura 100% pedagógica em 3 níveis (Plano de Ensino -> Módulos -> Aulas do módulo), sem vínculo com valores financeiros
Financeiro : Gestão de receitas, despesas, transações e fluxo de caixa
Planos de Pagamento : Gestão das modalidades (Individual ou Turma), periodicidades (Mensal, Trimestral ou Semestral), valores de mensalidade e regra de 20% de desconto para 2ª matrícula (familiar ou próprio aluno)
Relatórios : Emissão e exportação corporativa de dados em PDF
Usuários : Cadastro de operadores com controle granular de permissões (inclusive para Planos de Pagamento)
Auditoria : Rastreabilidade integral (quem fez, quando, tela e alteração)
Configurações : Dados da escola (nome, logotipo, contatos, CNPJ e status do MongoDB)
Login : Tela de entrada com autenticação segura


3. REGRAS DE NEGÓCIO PRINCIPAIS
--------------------------------------------------------------------------------
- Créditos de Remarcação 100% Automáticos:
  * Não há inserção ou remoção manual de créditos de remarcação/reposição.
  * Concessão: +1 crédito concedido automaticamente quando uma aula tem falta justificada.
  * Consumo: ao agendar reposição, o sistema valida saldo > 0 e debita 1 crédito.
  * Estorno: ao cancelar ou excluir uma aula de reposição agendada, o crédito retorna imediatamente ao aluno.

- Desacoplamento Pedagógico vs Financeiro:
  * Planos de Ensino cuidam apenas do conteúdo educacional e grade de aulas.
  * Planos de Pagamento cuidam das mensalidades, modalidades (Individual / Turma) e periodicidades (Mensal, Trimestral, Semestral).
  * Regra de Segunda Matrícula: 20% de desconto automático concedido para familiares ou para o mesmo aluno em novo curso.


4. ARQUITETURA E BANCO DE DADOS (NUVEM)
--------------------------------------------------------------------------------
- Nuvem : Vercel Serverless Functions (`/api/sync`)
- Banco de Dados : MongoDB Atlas (`acusticamente_db`) integrado à Vercel
- Variável de Ambiente : `MONGODB_URI`
- Sincronização : Automática e bidirecional entre computadores e celulares
- Modo Offline : Fallback transparente caso o dispositivo fique sem internet


5. ESTRUTURA DE ARQUIVOS
--------------------------------------------------------------------------------
api/ : API Serverless para conexão, leitura e escrita no MongoDB Atlas
src/views/ : Telas visuais do sistema que o usuário vê e usa (alunos, agenda, planos, planosPagamento, financeiro, etc.)
src/services/ : Serviços de armazenamento (storageService), auth e auditoria
src/types/ : Tipos TypeScript e esquemas de dados das coleções
src/styles/ : Sistema de design dark-mode, tipografia e responsividade
src/utils/ : Ferramentas auxiliares (avisos toast, modais, máscaras e manipulação de datas)
